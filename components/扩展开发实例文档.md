# SimComp-Tools 扩展开发实例文档

## 一、扩展开发概述

本文档旨在系统性地指导开发者完成 SimComp-Tools 扩展的开发制作过程。通过本文档，您将了解如何创建、开发、调试和发布自己的扩展组件。

## 二、开发环境准备

1. 确保您已经安装了 SimComp-Tools
2. 了解基本的 JavaScript 编程知识
3. 了解浏览器开发者工具的使用

## 三、组件的基本结构

每个 SimComp-Tools 扩展组件都遵循相同的基本结构。以下是一个标准的组件模板：

```javascript
const BaseComponent = require("../tools/baseComponent.js");
const { tools, componentList, runtimeData, indexDBData, feature_config } = require("../tools/tools.js");

// 组件名称
class 组件类名 extends BaseComponent {
  constructor() {
    super();
    this.name = "组件名称";
    this.describe = "组件描述";
    this.enable = true; // 默认是否启用
    this.tagList = ['标签1', '标签2']; // 组件标签
  }
  
  // 组件功能列表
  commonFuncList = [{
    match: () => 判断条件, // 判断是否执行此功能
    func: this.功能方法名 // 要执行的功能方法
  }];
  
  // 具体功能实现
  功能方法名() {
    // 功能代码
  }
}

// 实例化组件
ew 组件类名();
```

## 四、组件核心属性说明

### 1. 基本信息属性

```javascript
this.name = "组件名称";
this.describe = "组件功能描述";
this.enable = true; // true 表示默认启用，false 表示默认禁用
this.canDisable = true; // 是否允许禁用，默认为 true
this.tapCount = 0; // 组件优先级，数字越小优先级越高
this.tagList = ['标签1', '标签2']; // 用于分类和搜索
```

### 2. 数据存储属性

```javascript
// 组件运行时数据，不会持久化存储
componentData = {
  // 可以定义各种组件需要的运行时变量
};

// 持久化存储的数据，会保存在 IndexedDB 中
indexDBData = {
  // 定义需要持久化存储的配置项
};
```

### 3. 样式定义

```javascript
// CSS 样式定义
cssText = [
  `样式规则1`,
  `样式规则2`
];
```

### 4. 功能列表

```javascript
// 启动时执行的功能列表
startupFuncList = [
  this.初始化方法1,
  this.初始化方法2
];

// 根据条件触发的功能列表
commonFuncList = [{
  match: () => 条件判断, // 当此函数返回 true 时执行 func
  func: this.功能方法
}, {
  // 可以定义多个功能项
}];
```

## 五、开发步骤详解

### 步骤一：创建组件文件

1. 在 `components` 目录下创建一个新的 JavaScript 文件，命名格式为 `功能名称.js`
2. 使用基本模板填充文件内容

### 步骤二：设置组件基本信息

```javascript
constructor() {
  super();
  this.name = "示例组件";
  this.describe = "这是一个示例组件，用于展示开发流程";
  this.enable = true;
  this.tagList = ['示例', '教程'];
}
```

### 步骤三：定义功能触发条件

根据您的组件需要实现的功能，定义相应的触发条件：

```javascript
commonFuncList = [{
  // 当页面 URL 包含特定路径时触发
  match: () => Boolean(location.href.match(/特定路径/)),
  func: this.主要功能
}];
```

### 步骤四：实现具体功能

```javascript
主要功能() {
  try {
    // 获取页面元素
    let targetElement = document.querySelector("选择器");
    
    // 检查元素是否存在
    if (!targetElement) return;
    
    // 实现具体功能
    // 例如修改样式
    Object.assign(targetElement.style, {
      backgroundColor: "red",
      fontSize: "16px"
    });
    
    // 或者添加事件监听
    targetElement.addEventListener("click", () => {
      // 点击事件处理
    });
    
  } catch (error) {
    // 错误处理
    tools.errorLog(error);
  }
}
```

### 步骤五：添加样式（如需）

如果您的组件需要自定义样式，可以添加 cssText 属性：

```javascript
cssText = [
  `#自定义元素ID {
    background-color: rgba(0, 0, 0, 0.5);
    color: var(--fontColor);
    padding: 10px;
    border-radius: 5px;
  }`
];
```

### 步骤六：添加设置界面（如需）

如果您的组件需要用户自定义设置，可以实现 settingUI 方法：

```javascript
settingUI = () => {
  let newNode = document.createElement("div");
  let htmlText = `<div class=header>组件设置</div><div class=container>
    <table>
      <tr>
        <td>设置项</td>
        <td><input class=form-control type=text value="${this.indexDBData.settingValue}"></td>
      </tr>
    </table>
    <div><button class="btn script_opt_submit">保存</button></div>
  </div>`;
  
  newNode.id = "组件IDSetting";
  newNode.className = "col-sm-12 setting-container";
  newNode.innerHTML = htmlText;
  
  // 添加保存事件
  newNode.querySelector(".script_opt_submit").addEventListener("click", () => {
    // 保存设置到 indexDBData
    this.indexDBData.settingValue = newNode.querySelector("input").value;
    tools.saveDBData(); // 保存数据
  });
  
  return newNode;
}
```

### 步骤七：实例化组件

在文件末尾添加实例化代码：

```javascript
new 组件类名();
```

## 六、常用工具函数

SimComp-Tools 提供了一系列工具函数，可以在 `tools` 对象中访问：

1. **DOM 操作相关**
   - `tools.getParentByIndex(node, index)`: 获取指定元素的父元素
   - `tools.createElement(html)`: 创建 HTML 元素
   - `tools.appendToTarget(target, node)`: 将元素添加到目标位置

2. **数据处理相关**
   - `tools.saveDBData()`: 保存数据到 IndexedDB
   - `tools.loadDBData()`: 从 IndexedDB 加载数据
   - `tools.errorLog(error)`: 记录错误日志
   - `tools.log(message)`: 记录普通日志

3. **其他实用函数**
   - `tools.getBuildKind(buildingId)`: 获取建筑类型
   - `tools.getRealm()`: 获取当前服务器（R1/R2）

## 七、完整示例：创建一个简单的样式修改组件

下面是一个完整的示例，展示如何创建一个简单的样式修改组件：

```javascript
const BaseComponent = require("../tools/baseComponent.js");
const { tools, componentList, runtimeData, indexDBData, feature_config } = require("../tools/tools.js");

// 示例样式修改组件
class exampleStyleModifier extends BaseComponent {
  constructor() {
    super();
    this.name = "示例样式修改器";
    this.describe = "修改特定页面元素的样式";
    this.enable = true;
    this.tagList = ['样式', '示例'];
  }
  
  // 定义组件需要的持久化数据
  indexDBData = {
    backgroundColor: "rgba(0, 0, 0, 0.7)",
    textColor: "white"
  };
  
  // 定义CSS样式
  cssText = [
    `#script_example_modified {
      transition: all 0.3s ease;
    }`
  ];
  
  // 定义功能列表
  commonFuncList = [{
    // 在特定页面触发
    match: () => Boolean(location.href.match(/特定页面路径/)),
    func: this.modifyStyle
  }];
  
  // 实现样式修改功能
  modifyStyle() {
    try {
      // 获取目标元素
      let targetElement = document.querySelector("特定选择器");
      
      // 检查元素是否存在
      if (!targetElement) {
        tools.log("未找到目标元素");
        return;
      }
      
      // 添加标识类
      targetElement.id = "script_example_modified";
      
      // 应用样式
      Object.assign(targetElement.style, {
        backgroundColor: this.indexDBData.backgroundColor,
        color: this.indexDBData.textColor,
        padding: "10px",
        borderRadius: "5px"
      });
      
      tools.log("样式修改成功");
      
    } catch (error) {
      tools.errorLog("样式修改失败: " + error);
    }
  }
  
  // 添加设置界面
  settingUI = () => {
    let newNode = document.createElement("div");
    let htmlText = `<div class=header>样式修改器设置</div><div class=container>
      <table>
        <tr>
          <td>背景颜色</td>
          <td><input class=form-control type=text value="${this.indexDBData.backgroundColor}" id="script_example_bgcolor"></td>
        </tr>
        <tr>
          <td>文字颜色</td>
          <td><input class=form-control type=text value="${this.indexDBData.textColor}" id="script_example_textcolor"></td>
        </tr>
      </table>
      <div><button class="btn script_opt_submit">保存</button></div>
    </div>`;
    
    newNode.id = "exampleStyleModifierSetting";
    newNode.className = "col-sm-12 setting-container";
    newNode.innerHTML = htmlText;
    
    // 添加保存事件
    newNode.querySelector(".script_opt_submit").addEventListener("click", () => {
      this.indexDBData.backgroundColor = newNode.querySelector("#script_example_bgcolor").value;
      this.indexDBData.textColor = newNode.querySelector("#script_example_textcolor").value;
      tools.saveDBData();
      
      // 立即应用新样式
      this.modifyStyle();
    });
    
    return newNode;
  }
}

// 实例化组件
new exampleStyleModifier();
```

## 八、调试和测试

1. **使用浏览器控制台**：可以使用 `tools.log()` 和 `tools.errorLog()` 函数输出调试信息
2. **检查元素变化**：使用浏览器的开发者工具检查元素是否按预期变化
3. **测试不同场景**：确保组件在不同页面和不同条件下都能正常工作
4. **错误处理**：始终使用 try-catch 包装可能出错的代码块

## 九、注意事项和最佳实践

1. **遵循命名规范**：组件类名使用驼峰命名法，文件使用小写和下划线
2. **避免全局污染**：所有代码都应该封装在组件类中
3. **性能优化**：避免频繁的 DOM 操作，合理使用缓存
4. **错误处理**：始终处理可能出现的错误，提供友好的错误提示
5. **代码注释**：添加适当的注释，说明组件的功能和关键代码的作用
6. **兼容性**：确保组件在不同浏览器中都能正常工作
7. **用户体验**：提供清晰的设置界面和使用说明
